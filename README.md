# AndroidFrp

## 简介

- AndroidFrp 是一个运行在安卓手机上的内网穿透客户端
- 支持 ChmlFrp、ME Frp、MSLfrp 三家第三方平台
- 本身不提供穿透服务，只调用平台官方接口取配置
- 在本机以子进程方式运行官方 frpc 内核
- 相当于把电脑上敲命令行，换成手机上点几下

## 适用场景

- 家里宽带没有公网 IP，需要把内网设备暴露到公网
- 典型对象：NAS、路由器后台、家用摄像头、开发机 SSH、临时自建网站
- 或者人不在家，需要远程连回内网设备

## 主要能力

- 三家平台账号管理，网页登录与手动 Token 双通道
- 同时挂多个账号，支持跨平台混用
- 隧道列表展示在线状态与内外网地址
- 勾选隧道后一键启动
- 多节点自动拆成独立进程，互不影响
- 实时日志，可复制、可清空
- 悬浮窗显示状态、实时上下行速率、本次累计流量
- 保活四档可调
- 保活体检页，一键跳转系统设置
- ChmlFrp、ME Frp 支持 App 内增删改隧道
- 断线自动重连，指数退避，最长 30 秒

## 技术说明

- 语言：Kotlin + Jetpack Compose
- 最低系统：Android 10（API 29）
- 架构：arm64-v8a、armeabi-v7a
- frpc 以 libfrpc_*.so 随包分发，从系统库目录执行
- 不需要 root

# 使用教程

## 一、安装与首次启动

1. 安装 AndroidFrp-1.0.6.apk
2. 要求 Android 10 及以上
3. 允许「安装未知来源应用」
4. 首次启动会弹出「设置联系邮箱」
5. 该邮箱会写入请求头，格式为 Androidfrp/版本号 加邮箱
6. 仅平台方可见，用于账号异常时联系你
7. 可以不填，直接点「跳过」
8. 打开「设置 → 保活体检」逐项授权
9. 通知权限：不给则常驻通知不显示，服务容易被回收
10. 悬浮窗权限：不给则悬浮窗不可用
11. 电池优化：设为「不限制」
12. 国产 ROM 还需额外允许「自启动」和「后台运行」

## 二、添加账号

1. 首页点「添加账号」
2. 先选平台，再选登录方式

### 方式一：网页登录

- 点「打开 XX 登录页」
- App 内会打开平台官方登录页
- 正常输入账号密码即可
- ChmlFrp 会跳转到统一认证页面
- 登录成功后 App 每 2 秒静默检查一次凭据
- 读到凭据自动返回，不需要手动点按钮
- 若页面白屏或加载失败，说明当前网络访问该域名受阻
- 此时直接改用方式二

### 方式二：手动填 Token

- 在平台网页端复制令牌
- 粘贴到「访问令牌 / Token」输入框
- 三家取令牌的位置不同，这点最容易搞错

**ChmlFrp**

- 令牌在浏览器 localStorage 的 chmlfrp_auth_tokens 中
- 也可以从开发者工具里取
- 三段式 JWT 会按 access_token 处理
- 其他格式按 refresh_token 处理
- App 会自动续期

**ME Frp**

- 去面板个人中心获取「访问密钥」
- 注意不是「用户密钥」，两者不同

**MSLfrp**

- 取浏览器 Cookie 里的 auth_token
- 面板上的「Frp 系统 Token」不能用于 API
- 这是最常见的踩坑点

**MSL 兜底方案**

- 若接口字段变动导致读取失败
- 添加账号时展开「手动 TOML 配置」
- 把平台给出的 frpc TOML 粘进去即可正常运行

## 三、启动隧道

1. 首页账号卡片会显示该账号下的隧道数量
2. 点进「隧道列表」可查看内网地址、公网地址、在线状态
3. 回到卡片，隧道默认全部勾选
4. 不需要的隧道点掉勾选
5. 点「启动 N 条」
6. 启动耗时约 1 到 3 秒
7. 卡片状态变为「运行中」
8. 需要细节时点右上角「更多 → 查看日志」
9. frpc 输出全在日志里，出问题优先看它

### 停止的三种方式

- 卡片上的「停止」：只停当前账号
- 通知栏的「全部停止」：停所有账号
- 悬浮窗长按后 4 秒内再点一次：停所有账号

## 四、悬浮窗怎么看

悬浮窗共三行：

- 第一行「2 组 · 3 进程」：运行中的账号数与 frpc 进程数
- 第二行「↑ 128 KB/s ↓ 2.4 MB/s」：实时上下行速率，1.5 秒刷新
- 第三行「本次 ↑46.2 MB ↓812 MB」：本次运行的累计流量

### 操作方式

- 拖动：按住直接拖，位置会被记住并限制在屏幕内
- 单击：回到 App 主界面
- 长按：悬浮窗变红并显示「再点一次确认」
- 4 秒内再点一次才会真正全部停止，超时自动取消

### 数值说明

- 速率取自系统 UID 流量计数
- 包含 App 自身开销，如界面刷新与日志写入
- 该开销远小于隧道流量，看趋势没问题
- 少数 ROM 不提供此计数，会显示「流量统计不可用」
- 这属于系统限制，不影响隧道本身

## 五、保活强度怎么选

- 关闭：不启动前台服务，切后台即停，悬浮窗随之消失
- 关闭档最省电，适合只在 App 前台时使用
- 标准：前台服务加常驻通知，不申请电池优化
- 标准为默认值，日常够用
- 强力：标准基础加忽略电池优化和 Wi-Fi 锁
- 强力适合需要长时间挂着、偶尔掉线的场景
- 极限：强力基础再加 CPU 唤醒锁
- 极限适合熄屏也必须稳定在线，明显耗电，谨慎开启

### 关于 DNS

- 设置里有「DNS 服务器」，默认 223.5.5.5
- 若日志出现 no such host
- 先尝试换成节点 IP
- 或在此处更换可用 DNS

## 六、常见问题

**问：登录页打不开或白屏？**

答：换网络，或改用 Token 方式。登录页走平台官方域名，被拦截时 App 无能为力。

**问：ME Frp 启动时报「请使用生成启动配置」？**

答：1.0.2 起已改为调用官方接口取配置，不再自行拼装。若仍出现，说明平台又改了接口，重新「刷新隧道」拉取一次配置再试。

**问：MSL 读不到隧道？**

答：九成是把面板的「Frp 系统 Token」当成了 auth_token。改用浏览器 Cookie 里的 auth_token，或用「手动 TOML 配置」兜底。

**问：显示运行中，但外网访问不通？**

答：按顺序查三件事。第一，平台面板里隧道是否在线、域名与端口是否已分配。第二，本地服务监听的是 0.0.0.0 还是 127.0.0.1，必须是前者。第三，手机当前网络是否限制出站连接。

**问：锁屏一会儿就断？**

答：保活调到强力或极限，并在系统设置里开启自启动、后台运行、关闭省电限制。国产 ROM 的这三项是断线主因。

**问：流量那行显示不可用？**

答：部分 ROM 不提供 UID 流量计数，不影响隧道本身。

**问：拖动悬浮窗会导致断开？**

答：这是 1.0.5 的缺陷，1.0.6 已修复，升级即可。

## 七、需要注意的边界

- 不做签到功能
- ME Frp 的签到接口强制人机验证，客户端无法完成
- 请到网页端签到
- 实名与备案要求由平台决定，本应用不绕过任何限制
- 仅建议个人自用或小范围分享
- 不要用来对外提供未备案的公网 Web 服务
- 同一平台多账号、多平台混用都没问题，各跑各的进程
